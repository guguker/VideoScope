# VideoScope evidence snapshots

Этот каталог содержит только отобранные снимки реально запущенного локального
приложения. Это датированные иллюстрации, а не автоматически обновляемая
документация и не доказательство текущего состояния `master`.

Снимки `01`–`07` сделаны 24 июля 2026 года на локальной библиотеке из четырёх
видео. На них показаны библиотека и плеер, статусы провайдеров, окно локального
evaluation harness, речевой поиск, очередь клипов, загрузка и мобильная раскладка.
`2026-08-01-basketball-event-card.png` показывает структурированную карточку
баскетбольного события на версии интерфейса от 1 августа 2026 года.

Числа на изображениях могут устареть после изменения кода, моделей, индексов или
локального набора видео. Актуальные тесты следует получать из CI, а локальный
evaluation report — запускать заново после изменения контрольных кейсов.
Отчёт также становится устаревшим после смены моделей, доступности провайдеров,
словаря, поисковых порогов, схемы или методологии метрик.

Исторические JSON-снимки спортивного эксперимента сохранены в
[`docs/benchmarks/basketball`](../benchmarks/basketball/README.md). Их ограничения
описаны рядом с файлами; неподтверждённые метрики не переносятся в основной README.

Generated browser traces, промежуточные рендеры, дубли скриншотов и персональные
учебные материалы намеренно не хранятся в репозитории.
