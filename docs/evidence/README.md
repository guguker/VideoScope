# VideoScope: проверенное состояние проекта

Проверено 24.07.2026 на текущем рабочем дереве без изменения кода приложения.
Эти значения являются общей фактической основой для README, отчёта, дневника
практики и презентации.

## Автоматизированные проверки

- Backend: `171 passed`, покрытие `83,20%` при обязательном пороге `80%`; время pytest `4,70 с` (`real 5,46 с`).
- Frontend: `8 passed` в `3` test-файлах; длительность Vitest `508 мс` (`real 1,31 с`).
- Итого unit/component tests: `179 passed`.
- Production-сборка: успешно; TypeScript + Vite, `1588` модулей, `666 мс`.
- Артефакты сборки: JS `241,31 kB` (`73,90 kB gzip`), CSS `27,69 kB` (`6,19 kB gzip`).

## Benchmark поиска

Источник: `data/evaluation/latest-report.json`, сформирован 23.07.2026 21:40:58 UTC.
Отчёт охватывает 6 запросов. В текущем наборе уже 8 запросов, потому что позже
добавлены 2 баскетбольных эталона; нельзя приписывать старые метрики всем 8 случаям.

| Режим | Recall@1 | Recall@3 | Recall@5 | MRR | mean temporal IoU | mean latency |

Во всех шести случаях режима Auto релевантный результат был на позиции 1.

Отдельная спортивная проверка пока экспериментальная:

- в `output/e2e-three-pointer-final.json` два размеченных попадания находятся на
  позициях 6 и 18; то есть одно из двух попало в top-10, оба — в top-20;
- строгий 4-кейсный storyboard-тест Qwen 3.5 9B дал event accuracy `0,50` и jersey
  accuracy `0,00`; поэтому Qwen используется как один из подтверждающих сигналов,
  а не как самостоятельный классификатор типа броска и номера игрока.

## Текущее состояние приложения

- В библиотеке 4 готовых видео общей длительностью 8780,22 с, то есть 2:26:20.
- Суммарный размер исходных файлов — 2 422 252 667 байт (2,42 GB).
- Готовы 9 из 10 компонентов: FFmpeg, PySceneDetect, Whisper MLX, PaddleOCR,
  Roboflow RF-DETR, Lighthouse QD-DETR, Qdrant, SigLIP 2 и Qwen Video.
- Не настроен только внешний InternVideo 2.5; это опциональный GPU-reranker.
- Живой контрольный запрос `сделали МРТ` в режиме Speech вернул 12 результатов;
  первым — точное совпадение `00:56–00:59`, добавленное в очередь как `56,2–59,4 с`.

## Входные данные и защита

- Контейнеры: AVI, M4V, MKV, MOV, MP4, WebM.
- Максимальный размер файла по текущей конфигурации: 12 GiB.
- Пустые и слишком большие файлы отклоняются; имя нормализуется, путь пользователя
  не используется как путь хранения.
- Видео проверяется через FFprobe, затем ставится в последовательную фоновую очередь.

## Сценарии демонстрации

1. Добавить видео и показать допустимые контейнеры.
2. Дождаться фоновой индексации и проверить статус моделей.
3. Выбрать область поиска и канал: Auto, Speech, Visual или OCR.
4. Найти фразу `сделали МРТ`; открыть первый результат на точном таймкоде.
5. Показать мультимодальную временную шкалу и объяснение совпадения.
6. Добавить интервал `56,2–59,4 с` в очередь, отредактировать границы.
7. Экспортировать очередь в MP4 через FFmpeg.
8. Открыть окно качества и сравнить Recall, IoU и latency режимов.
9. Показать адаптивную мобильную компоновку.
10. Для спортивного профиля показать запрос `игрок забивает трехочковый`:
    плотный SigLIP-поиск формирует кандидатов, Qwen Video подтверждает событие.
