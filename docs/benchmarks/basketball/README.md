# Historical basketball snapshots

Здесь сохранены два небольших результата локального эксперимента, на которые
раньше ссылалась документация:

- `search-results.json` — 20 результатов запроса «игрок забивает трехочковый»;
- `qwen-storyboard-eval.json` — четыре ручных storyboard-кейса Qwen3.5 9B.

Это архивные evidence-файлы, а не воспроизводимый benchmark. Исходный экспорт не
содержал дату запуска, commit SHA, хеш набора данных, версии всех индексов и
контрольные суммы исходного видео. Локальные `video_id` также не переносятся между
установками. Поэтому файлы пригодны для разбора старого результата и схемы данных,
но не для сравнения новых моделей.

Для нового проверяемого прогона нужно сохранить manifest как минимум с commit SHA,
каноническим хешем кейсов, версиями моделей и конфигурации, идентификатором/хешем
набора видео и временем запуска. Generated `data/evaluation/latest-report.json`
остаётся локальным и исключён из Git.
